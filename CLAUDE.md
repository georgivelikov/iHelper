## Key decisions (do not re-litigate without asking)
- **Modular monolith**, not microservices: one Spring Boot app, feature packages (`task`, `category`, `sync`, `common`), layers controller → service → repository
- **Stack:** Java 25, Spring Boot 4.1, Maven, Flyway; React + TypeScript + Vite + TanStack Query
- **PostgreSQL everywhere** (dev, tests, e2e, hosted) via Docker. No H2.
- **One API for web and mobile:** versioned `/api/v1`, OpenAPI → generated TS `api-client`, UUIDs generated by clients, `version` + `deletedAt` + `/sync`, RFC 9457 errors, stateless (JWT later)
- **Testing:** JUnit 5 + Mockito (unit), `@WebMvcTest`/`@DataJpaTest` (slice), Testcontainers PostgreSQL `*IT.java` (integration), OpenAPI snapshot, Vitest + RTL + MSW, Playwright (desktop + mobile viewport)
- Starter categories (per user, at registration): Personal, Ideas, Work, Books, Shopping. "Home" in the UI is the all-tasks view, not a category.
- Mobile (Expo/React Native) is **Phase 7**, after web hosting (Phase 6)
